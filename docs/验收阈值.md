# 验收阈值（先定，再测）

写这份文件的原因很直接：**先有阈值，测试才有意义**。只跑到仿真终止时间、或者
"看起来站住了"，都不算通过。以下阈值需要在实机/台架之前由任务方确认，确认后
测试脚本直接引用这些数字，不允许事后下调。

参照 `CJ003_轮腿仿真完整包_v1.1.0` 的做法（其技术路线文档明确要求"验收前先写清阈值"）。

## A. 台架（悬空，只使能轮子，腿锁死）

| 项目 | 阈值 | 说明 |
|---|---|---|
| 连续运行时长 | **60 s** 不发散、不触发故障 | 当前 SIL 已过 20 s |
| 俯仰峰值 | **≤ 6°** | SIL：6 s 4.01°、20 s 4.03° |
| 力矩上限 | **≤ 10% 额定连续力矩** | 首次上电 |
| 急停响应 | 从按下到输出为 0 **≤ 20 ms** | 需实测，含 CAN 帧时间 |
| 断 CAN | 100 ms 内输出归零并锁存故障 | 不能靠"读不到就当 0" |
| 传感器 NaN | 单次出现即锁存故障 | 已有单元测试 |
| 单轴方向 | 6 个电机逐一手动确认 | 与模型符号一致 |

## B. 落地（吊装，允许触地）

| 项目 | 阈值 |
|---|---|
| 落地阶段俯仰峰值 | **≤ 10°** |
| 稳定窗口 | 触地后 **3 s** 内进入 \|pitch\| ≤ 5° 且 \|vx\| ≤ 0.05 m/s |
| 法向力 | 不出现持续为 0（脱地）；峰值记录归档 |
| 打滑 | 滑移速度持续 > 0.05 m/s 的时间占比 **< 10%** |
| 触地判定 | 必须由法向力/高度联合判定，不得按时间表切换 |

## C. 行驶（脱架前）

| 项目 | 阈值 |
|---|---|
| 终点误差 | 1 m 指令，**≤ 0.1 m** |
| 末速度 | 停止后 2 s 内 \|vx\| ≤ 0.02 m/s |
| 期间俯仰 | ≤ 8° |
| 力矩饱和 | 任意电机饱和时间占比 < 5% |

## D. 明确不算通过的情况

- 只到仿真终止时间；
- 视频里看起来站住了（视频可能是日志重建）；
- 只在标称参数下通过（必须附带 ±20% 质量、±30% μ 的跑批结果）；
- 未记录接触力、力矩、饱和时间的运行。
